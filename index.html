Personal Google Drive integration

Gifto Rclone Drive

A private file-transfer workflow using the open-source rclone command-line application. It runs on the account owner's Windows computer and supports authorized Google Drive file operations, including listing, downloading, uploading, and updating existing files.

The account owner may use Codex and Claude to operate this workflow. Google authorization is handled through the owner's OAuth client. This website describes the integration; it does not offer account registration, file uploads, or a sign-in service.

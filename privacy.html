Gifto Rclone Drive

Privacy policy

Effective October 14, 2026

Gifto Rclone Drive is a personal integration for the Google account owner. It uses rclone on the owner's Windows computer to perform file operations that the owner authorizes.

Google Drive access and purpose

The integration requests the Google Drive scope needed to list and inspect existing files, download files, upload files, and update existing files. This scope also technically permits deletion; the workflow's authorization rules determine which operations may be performed. Access is used to carry out the owner's requested file-transfer and verification tasks.

Google API data is used for the integration's authorized functions under the Google API Services User Data Policy, including its Limited Use requirements.

Storage and data handling

OAuth credentials and tokens are stored in a private local rclone configuration. Local workflow records may contain file names, IDs, sizes, checksums, and delivery links. Requested file content and metadata are exchanged with Google's API to complete the authorized operation.

The owner may separately authorize Codex or Claude to operate the workflow or process project material. Those services have their own terms and privacy policies. Files are transferred only to destinations selected in the owner's workflow; they are not published on this website.

Access control, retention, and revocation

The owner controls the Windows computer, local configuration, workflow records, and Google Drive files. The owner can revoke this integration in their Google Account's third-party connections settings and remove its local configuration. Revoking access does not automatically delete existing local files, workflow records, or Google Drive deliveries.

This website

This static informational website does not contain an application sign-in, collect uploaded files, or use custom analytics or tracking scripts. It is hosted by GitHub Pages; GitHub may process normal hosting request information under its privacy statement.

Contact

For questions about the integration or its Google Drive access, use the support contact displayed on its Google OAuth consent screen.
